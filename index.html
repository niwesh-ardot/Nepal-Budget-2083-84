Method and caveat

Built from reconstructed markdown, not official legal text

The source documents were processed through OCR, flow correction, and markdown conversion. This website is designed for public understanding and analysis, not as an authoritative legal source.

1

OCR recovery

Text was reconstructed from official budget documents into clean, searchable markdown.

2

Flow correction

Page breaks, fragments, and table structure were cleaned so the documents behave like actual text.

3

Interactive layer

The website adds summaries, filters, charts, tariff lookup, and bilingual search.
